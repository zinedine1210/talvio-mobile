# Talvio Mobile

Flutter app for Talvio (multi-tenant HRIS) — role-based UI for `employee` and `hr_admin`.

- Full spec: `../talvio/SPEC.md`
- Counterpart backend: `../talvio-backend`

## Branching

- `main` = production-ready
- 1 feature = 1 branch (`feature/<name>`), merged to `main` after verified working

## Run

```
flutter run
```
