# Presensia Mobile

Flutter app for Presensia (multi-tenant HRIS) — role-based UI for `employee` and `hr_admin`.

- Full spec: `../presensia/SPEC.md`
- Counterpart backend: `../presensia-backend`

## Branching

- `main` = production-ready
- 1 feature = 1 branch (`feature/<name>`), merged to `main` after verified working

## Run

```
flutter run
```
